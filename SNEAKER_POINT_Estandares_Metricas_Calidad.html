SNEAKER POINT

Estándares y Métricas de Calidad
en la Ingeniería de Software

Aplicación de estándares y métricas de calidad al desarrollo de una plataforma web B2B para proveedores de tenis y pequeños negocios.

Presentación ejecutiva
01 · Contexto del proyecto

¿Qué es SNEAKER POINT?

Modelo de negocio

Marketplace web B2B que conecta proveedores, mayoristas y distribuidores de tenis con pequeñas tiendas y negocios locales.

Funciones principales

  • Registro y autenticación por roles.
  • Gestión de proveedores y productos.
  • Búsqueda, filtros y comparación.
  • Pedidos mayoristas y seguimiento.
La calidad debe acompañar todo el ciclo de vida del proyecto: planificación, desarrollo, pruebas, cambios y liberación.
02 · Marco de referencia

Estándares y guías aplicables

ISO/IEC 25010

Modelo central para definir y evaluar características de calidad del producto de software.

ISO/IEC/IEEE 29119

Referencia para procesos, documentación y actividades de pruebas de software.

ISO/IEC/IEEE 12207

Referencia para procesos del ciclo de vida: desarrollo, verificación, validación y mantenimiento.

IEEE 730

Guía para organizar responsabilidades y actividades de aseguramiento de calidad.

OWASP

Buenas prácticas para prevenir vulnerabilidades frecuentes en aplicaciones web.

Aplicación

No implica certificación: se utilizan como referentes técnicos para estructurar el marco de calidad.

03 · ISO/IEC 25010

Atributos de calidad priorizados

Adecuación funcional

Que las funciones implementadas satisfagan los requisitos definidos.

Seguridad

Protección de cuentas, sesiones, roles, rutas y datos del sistema.

Eficiencia de rendimiento

Respuesta adecuada al consultar catálogo, filtros, proveedores y pedidos.

Usabilidad

Facilidad para que proveedores y tiendas completen tareas clave.

Fiabilidad

Funcionamiento estable durante flujos críticos y operaciones repetidas.

Mantenibilidad

Capacidad de corregir y evolucionar el sistema con control de cambios.

06 · Gestión de defectos

Control de errores y severidad

Ciclo de un defecto

Detectar→Registrar→Clasificar→Corregir→Retest→Cerrar

Clasificación

Crítica Bloquea función esencial, compromete datos o seguridad.

Alta Afecta significativamente una función principal.

Media Impacto parcial; existe alternativa.

Baja Problema visual, textual o menor.

PDR = (Bugs resueltos / Bugs detectados) × 100
07 · Calidad como mecanismo de gestión

De la norma a la decisión

Estándar→Atributo→Métrica→Meta→Prueba→Resultado→Decisión

Ejemplo de aplicación

ISO/IEC 25010 → Seguridad → Cobertura de rutas privadas → Meta 100% → Pruebas de autorización → Resultado medido → Decisión de aprobar, corregir o repetir pruebas.

Así, la calidad deja de ser una descripción general y se convierte en un mecanismo objetivo de control del proyecto.

08 · Evaluación de calidad

Proceso de medición

1. Definir la característica

Seleccionar el atributo de calidad a evaluar: funcionalidad, seguridad, rendimiento, usabilidad, fiabilidad o mantenibilidad.

2. Establecer la métrica

Definir una fórmula o indicador cuantificable que permita medir el comportamiento observado.

3. Ejecutar la medición

Aplicar pruebas y registrar evidencia real del sistema, evitando utilizar valores simulados.

4. Comparar con la meta

Contrastar el resultado obtenido con el criterio de calidad definido y documentar si cumple o requiere mejora.

Las métricas permiten convertir la calidad en resultados objetivos y comparables.
09 · Conclusión

Calidad medible y verificable

Valor para SNEAKER POINT

  • Permite evaluar objetivamente el software.
  • Facilita la detección de desviaciones y defectos.
  • Relaciona características de calidad con evidencia de pruebas.
  • Permite comparar resultados contra metas definidas.

Resultado esperado

Un proceso de desarrollo donde cada versión se evalúa con criterios cuantificables de funcionalidad, seguridad, rendimiento, usabilidad, fiabilidad y mantenibilidad.

La calidad debe medirse: los estándares proporcionan el marco y las métricas permiten comprobar el nivel de cumplimiento alcanzado por SNEAKER POINT.
